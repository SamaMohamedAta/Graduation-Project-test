# Cura Scan – Cancer Awareness & Ingredient Risk Detection App

Cura Scan is my graduation project developed as an interactive mobile application that supports cancer awareness, prevention, and product safety.

The application helps users scan products, analyze ingredients, and detect potentially high-risk components to encourage safer and healthier choices.

---

## 🚀 Key Features

- Product scanning and ingredient analysis  
- High-risk ingredient detection  
- Cancer awareness and educational content modules  
- Secure user authentication and login using JWT  
- Favorites feature for saving products and important content  
- News widget with categorized cancer-related articles  

---

## 🛠 Technologies Used

### Frontend
- React Native

### Backend
- Spring Boot  
- REST APIs  
- JWT Authentication & Authorization
